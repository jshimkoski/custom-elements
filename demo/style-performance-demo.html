💻 Code Example

Here's how to implement performance-optimized components with style caching:

const OptimizedComponent = component('optimized-component', { state: { theme: 'light', size: 'medium', data: [] // Non-style dependency }, style: { css: (state) => ` .component { background: ${state.theme === 'dark' ? '#333' : '#fff'}; padding: ${state.size === 'large' ? '20px' : '12px'}; border-radius: 8px; transition: all 0.2s ease; } `, // Only recalculate when these properties change dependencies: ['theme', 'size'], cache: true }, styleOptimizations: { enableCaching: true, // Enable intelligent caching enableMinification: true, // Minify CSS output enableDeduplication: true, // Remove duplicate rules debounceMs: 16 // Batch updates for 60fps }, render: (state) => html` <div class="component"> Content: ${state.data.length} items </div> ` });
