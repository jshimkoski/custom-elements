each() vs TransitionGroup

Comparing flex & grid layouts with and without transitions

🎯 Key Differences

each() directive

  • ✅ No wrapper element - items are direct children
  • ❌ No built-in transitions - instant updates
  • ⚡ Lightweight - pure function, minimal overhead
  • 📦 Returns array - VNode[] of anchor blocks
  • 🎯 Best for: Simple lists without animations

TransitionGroup

  • ✅ Wrapper element - styleable via class/style props
  • ✅ Enter/leave/move transitions - smooth animations
  • 🎬 Preset animations - fade, slide, scale, etc.
  • 📦 Returns VNode - single wrapper element
  • 🎯 Best for: Animated lists with layout control

💡 Pro Tip: Use each() for simple lists where you control the parent container. Use TransitionGroup when you need animations and want to apply flex/grid directly to the animated container!
