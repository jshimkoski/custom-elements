📚 About Template Helpers

Template helpers are utility functions that make writing component templates easier, more readable, and more powerful. They provide enhanced syntax highlighting, better IDE support, and convenient utilities for common template tasks.

This showcase demonstrates all available template helpers with real-world examples that you can interact with and learn from.

🏷️ html``

Enhanced template literal for HTML with better IDE support and syntax highlighting. Handles dynamic values and provides a clean API for building templates.

🎨 css``

Template literal for CSS with syntax highlighting support. Perfect for writing CSS strings within your JavaScript/TypeScript code.

📋 classes()

Conditionally apply CSS classes based on object properties. Similar to popular libraries like clsx or classnames but optimized for our runtime.

🎯 styles()

Generate inline style strings from JavaScript objects. Converts property-value pairs into CSS style declarations.

🔗 ref()

Create typed element references with better TypeScript support. Simplifies DOM element access within component callbacks.

⚡ on()

Create event handlers with enhanced typing and better development experience. Provides clear event handler definitions.

💡 Usage Tips

  • Use html`` for all template strings to get better IDE support
  • Combine classes() with state properties for dynamic styling
  • Use styles() for dynamic inline styles instead of string concatenation
  • Import helpers from '../lib/template-helpers.js' in your components
  • Take advantage of TypeScript types for better development experience
  • Combine multiple helpers for complex UI scenarios
