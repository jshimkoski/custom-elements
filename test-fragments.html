Fragment Support Test for vFor

Test Overview

This page tests that vFor properly supports fragments (multiple root nodes) without requiring wrapper elements.

Expected: Each vFor item should render multiple nodes directly without additional wrapper divs. The generated HTML should show mixed content (text + elements) as direct siblings.

Live Test Component

What to Look For

  1. Fragment List: Each item should render as:
    • Text content (item name + colon)
    • Checkbox input (self-closing tag in fragment)
    • No wrapper div around each item
  2. Self-Closing Input Only: Each item should render as:
    • Checkbox input only (self-closing tag as single fragment)
    • No wrapper elements at all
  3. Multiple Root Nodes: Each item should render:
    • Numbered span
    • Bold item name
    • Separator span
    • All as direct siblings
  4. Mixed Content: Each item should render:
    • Text content
    • Button element
    • Horizontal rule (self-closing)
    • No artificial containers

Developer Tools Inspection

Open browser DevTools and inspect the rendered elements. You should see that:

  • The vFor items render as direct children of their containers
  • No additional wrapper <div> elements are created around fragment content
  • Text nodes and element nodes appear as siblings in the DOM tree
  • Self-closing tags like <input /> and <hr /> render properly in fragments
  • Single self-closing elements work as standalone fragments
  • Anchor blocks (#anchor comment nodes) provide proper boundaries for updates
