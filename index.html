Key Features

  • ✅ Reactive state management with automatic re-rendering
  • ✅ Template interpolation with full expression support
  • ✅ Inline event handlers with modifiers
  • ✅ CSS-in-JS with static, dynamic, and object-based styling
  • ✅ Computed properties with automatic dependency tracking
  • ✅ Global event bus for component communication
  • ✅ TypeScript-first with full type safety
  • ✅ Multiple APIs from ultra-simple to full-featured
