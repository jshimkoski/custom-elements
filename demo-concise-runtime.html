Before vs After Comparison

❌ Before (Verbose)

createReactiveComponent({
  tag: 'my-component',
  template: (state) => `...`,
  state: { count: 0 },
  attrs: {},
  events: {},
  refs: {},
  hooks: {
    onMounted: (state, api) => {
      console.log('Mounted');
    }
  },
  computed: {},
  debug: false
});

✅ After (Concise)

createReactiveComponent({
  template: (state) => `...`,
  state: { count: 0 },
  onMounted: (state) => {
    console.log('Mounted');
  }
  // 60% less boilerplate!
});
